How It Works

Forex Pulse uses simple, transparent calculations from recent exchange-rate history. The scores help describe conditions; they do not predict profit or tell anyone what to trade.

Momentum Score

Measures recent price movement, consistency, and broader trend context, then reduces the score when risk is elevated.

Risk Score

Uses recent volatility, drawdown from the recent high, and unusually large one-day movement to identify unstable conditions.

Volatility

Calculated from recent daily percentage changes so users can compare how noisy each pair has been.

Consistency

Checks how often recent daily movement agrees with the current trend direction.

Data Source

Live mode uses exchangerate.dev where available. Reference history uses Frankfurter API data and may not be a real-time dealing quote.
